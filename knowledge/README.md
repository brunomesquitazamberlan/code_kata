# Knowledge Base

This directory contains reusable lessons extracted from the katas.

It is intentionally practical: each note should connect a concept to code I actually wrote, reviewed, debugged, or refactored.

## Suggested concept note format

```markdown
# Concept Name

## In one sentence

Short explanation in my own words.

## Where it appeared

- Kata:
- File:
- Situation:

## Why it mattered

What changed in the design, readability, correctness, testability, or failure behavior?

## Common traps

- Trap 1
- Trap 2

## Trade-offs

When is this useful? When might it be overkill or misleading?

## References

- Official docs or high-quality references.
```
